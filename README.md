# 便笺 · Notes

[English](README.en.md) | 中文

> 产品名是「便笺」，仓库名沿用 `dsh-workspace-todos`。

一个给 DSH Web GUI 用的轻量会话便笺。每条记录只属于一个**会话**：切换会话不会串数据，也不会再按工作区共享。入口位于会话顶部右侧按钮，便笺面板固定从右侧打开。

![便笺右侧面板](./preview-right.png)

## 入口

会话顶部右侧的「便笺」按钮，带未完成数量：

![顶部右侧便笺按钮](./preview-right.png)

点击后在右侧打开固定面板，不再使用侧边栏会话标签或输入框底部入口。

## 功能

- 数据按**会话 ID** 隔离；同一个工作区的不同会话也各自独立。
- 顶部右侧保持 `28px` 正方形图标按钮，用低对比灰色角标显示未完成数；悬浮提示为「会话便笺 N」。
- 点击按钮在窗口右侧打开固定面板；切换会话时自动收起旧面板并更新入口。
- 便笺标题右侧的设置按钮展开设置卡片：可切换发送快捷键（Enter 发送，或 ⌘/Ctrl+Enter 发送，按键名随平台显示）；「一键转发」下提供单行起高的前缀提示词文本框（输入换行后自动增高至六行）和下方说明；底部显示版本、作者阿三石与可点击的 GitHub 项目地址，设置自动保存。
- 浮窗右上角对齐顶部入口按钮；DSH 右侧栏打开时自动左移，避免被右侧栏遮挡。
- 点击入口打开右侧面板：添加、打勾完成、复制、双击或铅笔编辑、删除、清除已完成（二次确认）、展开已完成。
- 拖动面板左边缘把手可调整宽度，双击把手复位；宽度会保存在浏览器中。
- 拖动面板底部中央把手可调整高度，双击把手恢复内容自适应；高度会保存。
- 未完成的便笺右侧提供复制、转发、编辑、删除；已完成的隐藏转发按钮，复制/编辑/删除保留。复制在编辑左侧，复制成功后由全局 Toast 提示，不再改动按钮本身。
- 转发只把每条便笺作为无序列表项 `- 内容` 追加；仅当输入框为空时写入设置中的前缀提示词（默认按界面语言，中文为「完成以下任务：」），已有内容时不再补前缀，光标停在末尾且不会自动发送。
- 转发成功后转发按钮显示勾选，并按会话记住转发状态；勾选框始终只表示未完成和已完成，不会被转发改变。
- 转发与完成状态互不影响：已完成便笺不显示转发按钮，勾选框保持完成态；已转发的便笺再次点击转发按钮会取消转发标识，不会重复追加。
- 勾选框与正文第一行合并；未完成行的复制/转发/编辑/删除放在底部时间行右侧，减少一行空间占用。
- 「清除已完成」需要二次确认：首次点击展开确认条，确认后才清除。
- 完成圆点视觉为 14px，点击区域 24px，与正文第一行文字中心对齐。
- 新增录入框和编辑框都会随内容自动增高为多行；录入框和二次编辑框都会沿用设置中的发送快捷键，另一种组合换行（macOS 显示为 ⌘+Enter，Windows 为 Ctrl+Enter），编辑框右侧显示当前快捷键提示。
- 新增框不再显示左侧加号；「添加」按钮固定在第二行右侧，输入换行时不会闪烁或跳动。
- 发送快捷键提示放在添加按钮左侧的空白处；切换设置后提示同步更新，输入框占位提示保持简洁。
- 新增和编辑中的草稿按会话自动保存；临时关闭面板后重新打开会恢复，光标停在草稿末尾，添加、保存、取消或删除后自动清除。
- 展开「已完成」不会压缩上方「未完成」列表；只有未完成与已完成区域内部滚动，标题、设置、录入框和底部保持固定。
- 「未完成」「已完成」标题在列表内吸顶：未吸顶时保持透明；真正贴到滚动区顶部后使用与浮窗一致的 `bg-layer-2` 表面，颜色统一，不再出现色差明显的整块背景。背景模糊暂不启用，待确认颜色效果后再决定。
- 已完成的便笺同时显示创建时间与完成时间，并按完成时间倒序排列；未完成的只显示创建时间。
- 「未完成」「已完成」的展开/折叠状态会记住，重新打开面板时恢复上次状态。
- 便笺卡片的复制/编辑/删除按钮默认隐藏，悬浮或键盘聚焦时显示；触屏设备保持常显。
- 「未完成」和「已完成」标题都可点击折叠，两侧计数样式和颜色保持一致；两者可独立展开，互不影响；点击区域仅限箭头、文字和计数，右侧空白不触发。
- 侧边栏提醒标签在生成期间保留，方便随时查看。
- 同一浏览器的多个标签页会同步更新。
- 中英文界面，跟随 DSH 语言设置。
- 界面样式全部复用 DSH 设计令牌：语义色别名、共享圆角与阴影、菜单材质、共享滚动条；字号收敛到 12 / 13 / 14 三档、字重上限 500、中性描边统一 0.5px；悬停只在支持 hover 的设备启用，瞬时结果走全局 Toast。详见 [UI / 交互规范复查报告](./docs/ui-design-check.md)。

## 设计规范

面板与入口按钮的样式由 `client.js` 顶部的令牌块统一驱动，改一处即可全站生效：

| 维度 | 令牌 | 取值 |
| --- | --- | --- |
| 颜色 | `--dsw-alias-*` | 直接复用 DSH 语义别名（墨色 / 悬停 / 描边 / 状态 / 设置卡），插件不再自建灰阶 |
| 字号 | `--wt-fs-caption/row/title` | 12 / 13 / 14，行高统一 20 |
| 字重 | 400 / 500 | 上限 500，强调靠字号与墨色 |
| 间距 | `--wt-space-1 … -6` | 4 / 8 / 12 / 16 / 24 / 32 |
| 圆角 | `--dsw-radius-sm/md/lg/panel` + 999 | 8（紧凑控件）/ 16（分组与字段）/ 28（浮动面板）/ 胶囊配 `corner-shape:round` |
| 阴影 | `--dsw-elevation-panel` | 浮层 `border:0`，0.5px 发丝描边画在阴影第一层 |
| 材质 | `--dsw-specific-menu` + `--dsw-menu-backdrop-filter` | 与 DSH 菜单 / popover 同一材质 |
| 动效 | `--ds-transition-duration*`、`--ds-ease-in-out` | 100 / 200ms，只动 opacity 与 transform |
| 滚动条 | 主题共享 skin | 面板内只重绑 `--dsh-scrollbar-*` 到 l2，并为列表设置 9px 轨道 / 2px 内缩 |

反馈层同样复用产品能力：复制、转发、删除、清除完成与写失败都经 `shell.overlay` 的全局 Toast 报告，浮窗关闭后仍然可见；图标按钮用 `ui-primitives` 的 `Tooltip`。

## 使用

1. 在会话标题后点击 `便笺 未完成数` 标签（有未完成条目时显示），或点击输入框下方状态条右侧的「便笺」。
2. 在浮窗里写一条具体的小事，按 Enter 或点「添加」。
3. 做完后点左侧圆圈打勾；点「已完成」展开回看。
4. 点浮窗外部或按 Esc 关闭。

## 数据保存在哪里

便笺保存在**当前浏览器**的 `localStorage` 中，键为 `dsh.session-memos.v1`，结构为：

```json
{
  "version": 1,
  "sessions": {
    "session-…": {
      "sessionId": "session-…",
      "updatedAt": 0,
      "items": []
    }
  }
}
```

因此：

- 刷新页面、重启 DSH、切换会话都不会丢。
- 不会写入项目文件，也不会同步到其他机器或其他浏览器。
- 清理浏览器站点数据会清除便笺。
- 旧版本的 `dsh.workspace-todos.v1`（按工作区）不会再读取；升级后需要重新记录。

## 安装

```bash
git clone git@github.com:Rayle8/dsh-workspace-todos.git
```

把克隆目录 link 进 DSH profile（把 `<path-to-repo>` 换成实际克隆目录）：

```json
{
  "dependencies": {
    "dsh-workspace-todos": "link:<path-to-repo>"
  },
  "dsh": {
    "profile": {
      "bundles": ["dsh-workspace-todos"]
    }
  }
}
```

然后在 profile 目录执行 `pnpm install`。DSH 启动时会读取 `dsh.bundle.patch` 和 `dsh.client`。新增插件行后，可以在侧边栏「插件」页对该组合包**关闭再开启**，让运行中的 Host 在线重新组合，无需重启；如果插件页里还看不到它，再重启一次 DSH。之后单独修改 `client.js` 时，开发模式的 HMR 会直接替换 bundle。

## 开发

`client.js` 是浏览器半侧，采用 DSH 的 Module Loader 格式：

```js
window.__ModuleLoader__.load({
  id: 'dsh-workspace-todos',
  factory(require) {
    const React = require('react')
    return { inject: ['slots'], apply }
  },
})
```

`index.js` 是空的 Host 半侧；`cordis.patch.yml` 负责把包插入 profile 的组合。界面只依赖 `slots` 服务：

- `conversation.composer.dock`：输入框下方状态条右侧入口。
- 侧边栏标签通过 MutationObserver 注入到会话标题后，因为当前打包版的行内 trailing slot 未渲染。

浮窗用 `react-dom/client` 的独立 root 挂到 `document.body`，用 fixed 定位跟随入口；所有样式使用 DSH 的 `--dsw-alias-*` 主题变量，自动适配明暗主题。

修改 `client.js` 后，在开发模式下 DSH 的 client HMR 会自动替换 bundle；否则刷新页面或重启 DSH。

## 验证

已在独立的 DSH profile 中实际加载，并用无头 Chrome 走通：

- 会话标题后出现 `便笺 1/1` 标签；
- 点击标签/输入框入口，浮窗在入口附近打开；
- 添加后标签与浮窗数量同步；
- 浮窗内可完成、编辑、删除、清除已完成；
- 刷新页面后记录仍在，并按会话隔离。

`node --check client.js` 与合同测试也通过。
