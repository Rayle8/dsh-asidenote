# AsideNote 面板 UI 规则

面向后续改动的约束清单。历史复查的过程、逐项对照与截图已移除，只保留规则与待决项；当前界面截图见 [`docs/assets/`](./assets/)。

基准：DSH 宿主的 UI / UX 设计规范（令牌、字号、描边、浮层、滚动条与无障碍条款）。

## 1. 令牌与尺度

| 规则 | 落地 |
| --- | --- |
| 只用 DSH 语义别名，不自建色板 | `--dsw-alias-*`（墨色 / 悬停 / 描边 / 状态 / 设置卡）；测试禁止 `#hex`、`rgb()` 与平行灰阶 |
| 字号只取三档 | 标题 14/500、行与按钮 13/400、说明与计数 12/400；行高统一 20，计数行 16 |
| 字重上限 500 | 层级靠字号与墨色，不用 600 |
| 圆角按角色 | 浮窗 `--dsw-radius-panel`(28)、分组与字段 16、紧凑控件 8、胶囊 999 并配 `corner-shape:round` |
| 中性描边 0.5px | 虚线 1px、spinner 环 1.5px 为例外 |
| 浮层无边框 | `border:0` + `--dsw-elevation-panel`；0.5px 发丝线画在阴影第一层，不同时叠中性描边 |
| 滚动条用共享皮肤 | 不写组件私有 `::-webkit-scrollbar` 或 `scrollbar-width/color`；面板内只重绑 `--dsh-scrollbar-*` |
| hover 只在支持的设备启用 | 全部收进 `@media (hover:hover)`；触摸端行操作常显 |
| 动效只动 opacity / transform | 100 / 200ms，`--ds-ease-in-out` |
| 图标画布 36×36 | `icon.svg` 自包含，路径居中缩放 |
| 文案只来自字典 | `src/client/i18n/` 为唯一来源，中英逐键一致；中文提示不带句号 |

## 2. 面板基线尺寸

| 项 | 值 |
| --- | --- |
| 入口按钮 | 28×28，R8，未完成数为胶囊角标 |
| 面板头 | 标题 14/500 与计数 12/400 同行；设置 / 关闭收进右侧动作组 |
| 分区标题 | 12/500，`label-secondary` |
| 图标按钮 | 24×24，R8 |
| 勾选圈 | 视觉 14×14，命中区 24×24 |
| 录入区 | 0.5px 描边、R16、padding 12；添加按钮 H28、R8 |
| 行分隔线 | 0.5px |
| 列表滚动条 | 9px 轨道、2px 内缩、距面板边缘 16px |
| 窄视口 | ≤480px 时四边 12px，宽度按视口夹取 |

对比度（主题令牌的既有值，作为回归参考）：

| 文本 | 明 | 暗 |
| --- | --- | --- |
| 正文 / 标题 `label-primary` | 17.7:1 | 13.6:1 |
| 说明 / 时间 / 计数 `label-secondary` | 5.4:1 | 9.4:1 |
| 勾选圈描边 `label-tertiary`（非文本） | 3.5:1 | 6.7:1 |

`label-tertiary` 不承担文字：明色下只有 3.5:1，文字统一走 `secondary`。

## 3. 交互规则

- **入口**：会话顶部 28×28 按钮，未完成数作胶囊徽标；打开时 `data-active`，再次点击、点外部或 Esc 关闭，关闭后焦点回到入口。
- **反馈**：复制、转发、删除、清除完成与写失败都走 `shell.overlay` 的全局 Toast，面板关闭后仍可见；失败时不改动任何数据、草稿或转发标记。
- **六个状态**：默认 / 悬停 / 按下 / 键盘聚焦（主题 2px 环）/ 禁用 / 加载（按钮内 12px 环、`aria-busy`）。
- **浮层安全**：`position:fixed` + portal 到 body；宽高按视口夹取，只在下方确实放不下时才翻到锚点上方；顶边不低于 `--dsh-frame-overlay-top`；外侧 pointerdown 与 Esc 都能关闭。
- **响应式**：390×844 下四边 12px，标题与操作不截断；触摸设备操作按钮常显。
- **数据**：写失败保持原状；按会话隔离；1.x 数据首次加载时复制到 `dsh.aside-notes.*.v2`，旧键只读保留。

## 4. 测试守护

`npm test` 运行 45 条契约断言与 1 个 jsdom 集成测试。契约测试守住：

- 颜色 / 字号 / 间距 / 圆角 / 描边 / 浮层材质；
- 滚动条共享皮肤、hover 门控；
- 字典完整、中英一致、中文提示不带句号；
- Toast 座位、写失败保留数据、Tooltip 覆盖行内操作、移动端不主动聚焦；
- 已下线的整页实现不得回流。

jsdom 集成测试真实驱动构建产物：打开面板、添加、设置与快捷键、完成、清除二次确认、就地编辑、键盘缩放、删除到空态、分区记忆，以及 1.x 数据迁移。

## 5. 例外与待决

1. **入口按钮使用原生 `title`**：它由插件注入宿主 header 的 DOM（React portal 会被宿主重渲染回收），无法包共享 `Tooltip`；若宿主提供 header utilities 插槽，可统一。
2. **右侧浮窗不是侧栏 slot**：当前是锚定入口的浮窗；若产品希望常驻右侧栏，应改注册到 `rightbar`，属产品决策。
3. **链接与错误文本的明色对比度**：`--dsw-alias-link` 3.97:1、`--dsw-alias-state-error-primary` 4.22:1，低于 4.5:1；均为主题令牌，建议在主题层统一提升，插件内不覆盖。
4. **图标仍需设计师确认**：`icon.svg` 为 36 画布、自包含 SVG。
